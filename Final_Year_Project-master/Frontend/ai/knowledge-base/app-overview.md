# ColonyCarpool Overview

ColonyCarpool is a secure ride-sharing platform for residents of the same housing society.

## What the app does
- Lets residents sign up with approval-based onboarding.
- Lets approved users post rides, find rides, and join rides.
- Supports private chats and group chats around a ride.
- Tracks trust, reliability, savings, and CO2 impact.
- Includes an AI chatbot for app guidance and knowledge lookup.

## Main screens
- Landing page
- Login and signup
- Dashboard
- Society feed
- Leaderboard
- Profile
- Settings
- Admin dashboard
- Help and support

## Chatbot scope
The chatbot should answer questions about:
- How the app works
- Ride posting and ride searching
- Trust and reliability rules
- Approval and admin flow
- Feature explanations and project overview
- Help content stored in the knowledge base

The chatbot should not invent data or claim to perform actions it cannot actually perform.
