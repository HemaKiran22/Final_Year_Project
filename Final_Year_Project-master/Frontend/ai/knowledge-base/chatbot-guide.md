# Chatbot Guide

## What the chatbot should do
- Answer user questions using retrieval from the project knowledge base.
- Summarize app behavior, policies, and feature descriptions.
- Quote or reference relevant source documents when possible.
- Ask a clarifying question when the query is too broad.

## What the chatbot should not do
- It should not pretend to access private user records.
- It should not fabricate ride availability, status, or approvals.
- It should not directly perform database actions unless that feature is explicitly implemented elsewhere.

## Good prompts
- What is ColonyCarpool?
- How does approval work?
- What does the trust score mean?
- How do I find a ride?
- What does the admin dashboard do?
